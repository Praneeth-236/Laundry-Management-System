# Archived project iterations

The active application is the MERN app at the repository root. The directories here preserve the previous learning stages for reference; they are not used by the current server or container build.

- `c-prototype/main.c` is the original standalone C command-line laundry tracker.
- `flask-prototype/` is the earlier Flask web wrapper and its prototype files.

The C and Flask versions use local text files and are not production systems. The Flask archive includes the transition experiment made during this rebuild. Do not copy personal `users.txt`, closet/history files, or photos into a public commit.
